# Changelog

## LMDT 0.1.0

- Initial release of the `LMDT` package for CRAN submission.
- Implements the Local Manifold Dispersion Test for regression
  heteroskedasticity.
- Supports formula and matrix interfaces.
- Includes design-adapted Wild Bootstrap, permutation testing, and
  asymptotic normal calibration.
- Integrates Gavish–Donoho adaptive PCA and supervised metric learning
  for high dimensions.
