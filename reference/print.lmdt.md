# Methods for LMDT Test Results

Print and summary methods for objects of class `"lmdt"`.

## Usage

``` r
# S3 method for class 'lmdt'
print(x, digits = 4, ...)

# S3 method for class 'lmdt'
summary(object, ...)
```

## Arguments

- x:

  An object of class `"lmdt"`.

- digits:

  Number of significant digits.

- object:

  An object of class `"lmdt"`.

- ...:

  Additional arguments.

## Value

Invisibly returns the input object.
